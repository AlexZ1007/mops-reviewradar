Supabase Auth owns every account

We chose Supabase Auth and route it through our FastAPI gateway, so the UI never holds an auth key.

  • Registration

    Email and password; a profile is created by a database trigger

  • Login

    Supabase issues a JWT; FastAPI verifies it on every request

  • Session

    Refresh token in an HttpOnly cookie, so a reload keeps you signed in

Reviews can now enter a project

CSV import and a manual review form on the new Reviews page · FR03 · FR04 · NFR02

Upload a CSV

UTF-8, up to 2 MB. Comma, semicolon or tab is detected automatically.

Check the file

A content column is required. A file that can’t be read is rejected and nothing is saved.

Validate each row

Bad rows are reported with row, field and reason. Valid rows are still saved.

Skip duplicates

The same text, ignoring case and spacing, is counted, not saved twice.

Only owners and analysts can import; archived projects are read-only. Manual reviews get the same duplicate check, and every import is written to the audit log.
