02What changed since Checkpoint 1 · Authentication

Supabase Auth now owns every account

Integrated

Checkpoint 1 only listed “authentication”. We chose Supabase Auth and route it through our FastAPI gateway, so the UI never holds an auth key.

  • Registration

    Email and password sign-up; a profile is created automatically by a database trigger

  • Login

    Supabase issues a JWT; FastAPI verifies it on every request

  • Account & session

    Rotating refresh token in an HttpOnly cookie: the session survives a reload; sign out ends it
